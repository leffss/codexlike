# /status 报告回消息流带关闭按钮

ADR 0030 将全部本地命令反馈迁右下角 toast，实际使用发现：`/status` 是多行仪表盘报告，toast 的限高滚动与 info 类约 6 秒自动消失不适合细看。修订：仅 `/status` 成功报告恢复消息流内 status segment（`kind:"status"` 复活，事件接续时保留驻留），块内加关闭按钮按段 id 移除（再敲 `/status` 出新块，多条并存各自可关）；其余短反馈（`/compact`、`/rename`、各类失败与拦截提示）维持右下角 toast 不变，flash 基础设施照旧。曾考虑全部回退消息流（短反馈的自动消失与不占对话流体验随之丢失），弃。
