# 过程段逐段呈现，取代已工作折叠区

验收反馈：「已工作 N 秒」摘要行没有意义。该摘要是 [ADR 0011](0011-message-stream-timeline-model-and-reasoning-persistence.md) 引入的「已工作折叠区」的开关——轮完成后把最终正文之前的过程段（思考、中间正文、工具卡、子代理卡）整体收起，以一行工时摘要回看。实际使用中工时数字不可操作，摘要把用户真正想回看的过程藏在一层结构后面。本 ADR 移除折叠区，过程段逐段平铺呈现；ADR 0011 呈现分层中「以最终正文为界切分折叠区」的边界由本 ADR 取代，其余边界（时序行模型、跟随状态机、宽度分档等）不变。

## 关键边界

- 平铺常驻：轮内消息段按事件原序直接渲染，不再切分折叠；「穿透段显示在折叠区之后」的重排随之消失，交互/错误/状态段回到时序原位。
- 段自带工时：每个过程段统计并显示自己的耗时——活动段实时跳动、完成以 endedAt 定格、恢复的历史段缺打点省略（数据来源为段上的 at/endedAt/completedAt，不新增数据层字段）。
- 开合默认值（GLOSSARY「过程段」）：思考卡与子代理卡维持既有语义（流式默认展开、结束自动收起）；工具卡改为运行中默认展开、完成自动收起；被隔断的中间正文以折叠卡呈现、默认收起（流式正文只追加到序列末尾，隔断前它就是轮内最后一段正文、仍以气泡实时可见——隔断即失活，因此不存在「流式中折叠」的形态）。
- 开合记忆不覆盖手动操作：默认值随事实翻转（运行中→完成）只作用于未手动操作过的键，与 collapse-memory 既有语义一致。
- 工具分组保留：连续同类已完成的工具卡仍统计为组（组头计数 + 跨度，展开由原卡渲染），分组作用域从折叠区扩展到轮内全序列。
- 轮次视图简化：TurnView 不再携带 history/following 切分与轮级工时，只保留用户段、时序段序列、运行态与最终正文锚点（操作栏只挂轮内最后一段正文）。
- 中断/失败终态不再强制展开过程：失败原因靠错误段与部分正文（均常驻可见）表达，各过程段按统一规则自动收起，需要时手动展开。

## 取舍

拒绝保留折叠区只精简摘要文案：摘要行的价值不在工时数字而在收纳，而收纳的代价是每次回看都要先展开一层。拒绝彻底移除分段折叠、全部平铺不收起：工具多的轮次会把最终正文挤出可视区，收起态的一行摘要（思考摘要/参数摘要/计数）本身就是可读的过程索引。拒绝为「失败轮展开过程」保留特例：特例需要轮级开合状态，与逐段记忆模型冲突，且失败信息已由常驻的错误段与部分正文承载。

影响面：turn-view 纯函数、MessageStream、ToolCallCard、GLOSSARY「已工作折叠区」词条移除；e2e worked-history 场景改写为 process-segments（运行卡默认展开/完成自动收起为新增断言），其余 e2e 场景删除折叠区展开前置步骤。
