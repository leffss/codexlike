# 审批与问答统一用户交互，保存记录而不恢复执行

> 单条审批及不保留授权的约束已由 [ADR 0012](0012-persistent-session-auto-approval.md) 部分替代；问答仍需回应，重启仍不恢复执行。

执行审批和对话内交互问答共用用户交互模块，统一管理请求归属、等待、响应、取消、持久化及底部操作入口；保留两种响应的业务含义。审批仍由现有权限策略决定是否需要用户授权，问答不受自动放行档位影响，不能把“完全访问”理解为可替用户回答。

主代理与子代理的请求按所属会话排队，回应只恢复对应请求。切换会话不取消等待；停止任务或退出应用取消未完成请求，重启只恢复历史，不恢复执行上下文。持久化等待记录用于显示和审计，不代表可以重放工具；这是与完整任务检查点恢复之间的明确取舍。

已提交问答随触发它的用户消息保存结构化快照，并参与后续上下文和 Compact；不依赖助手复述，也不伪装成新的一轮用户发送。审批响应仍只决定对应操作的授权，不成为可复用的授权记忆。
