# 工作计划：主任务位长条形折叠卡退役，一行三胶囊过程条（计划/子代理/终端）

用户诉求：子代理列表与终端会话列表以工作计划卡同族形态加入工作计划挂载位，三者并排呈现。经三变体原型对比（分支 prototype/tri-list-cards：A 等宽三卡 / B 胶囊弹出 / C 主从浮层），用户选定变体 B 并经两轮迭代定稿：**一行三胶囊过程条（ProcessPillsBar）**——主任务位原长条形进度折叠卡（ADR 0019）退役，折叠卡本体保留供子代理详情页（ADR 0023 口径不变）。

## 关键边界

- **槽位不变**：消息正文与消息队列/输入框（或交互面板）之间，宽度对齐正文列（contentWidthClass + contentPadding，居中基准与消息列、输入区完全一致，同 ADR 0019 槽位）。
- **结构（变体 B）**：一行三胶囊（计划/子代理/终端）按内容宽度、整组居中，占行最矮；胶囊 = 图标 + 标题 + 运行计数徽章（>0 时）+ N 计数 + 折叠箭头。点任一胶囊**向上弹出浮动对话框**（消息流一侧空间大、下方是输入区）：绝对定位锚定被点的胶囊水平居中（不推挤布局）、max-h 内部滚动、点外 mousedown 收起；再次点击同胶囊 toggle 收起。
- **行点击直跳**：子代理/终端列表行复用消息流标记行语义（ADR 0032：右栏对应 tab 直跳详情页），行尾 hover「右栏查看 →」提示；跳转意图达成后浮层收起。计划浮层为步骤清单（三态图标对齐折叠卡展开态视觉）。
- **空态口径**：无内容的胶囊不渲染（对齐 ADR 0019「无计划不占布局行」），三类皆空整条渲染 null；有内容即常驻（计划完成/中断仍回看最后快照，同 ADR 0019）。
- **数据源**：计划快照与子代理段由消息段序列派生（lib/plan-view / lib/task-view「事件归并实体段」两处消费口径）；终端会话自装 useTerminalSessions——与右栏终端列表同源同数（组件内装配先例 RailPanel/useGitStatus）。
- **开合不做跨会话记忆**：浮层是一次性查看交互（点开→读→点行跳走/点外关），不像折叠卡常驻收起态，collapse-memory 记忆无对象；折叠卡的 collapse-memory 保留供子代理详情卡。
- **流内标记行不变**：update_plan 仍只留 PlanMarkerRow（ADR 0016/0019）。

## 取舍

- 拒绝变体 A（等宽三卡）：三卡各自展开后占行高数倍于一行胶囊，三列清单同时挤压正文滚动区；且多数时间用户只关注其中一类。
- 拒绝变体 C（主从浮层）：计划主体地位保留但两窄摘要卡信息弱（仅大数字计数），浮层固定右缘弹出与「点哪开哪」的空间对应弱于锚定式。
- 变体 B 定稿迭代：胶囊从等宽拉伸改按内容宽度；弹出面板从下方推挤改向上浮动对话框；锚定从整组居中改被点胶囊居中（用户三轮反馈）。
- 双份终端 IPC 订阅（本条 + RailPanel 各自装配）是已知代价：一次 list-for + 一份事件订阅，换接口极简（ProcessPillsBar 不要求调用方提升数据源）；量级小、先例同构。
- 运行态行内用时接 useTickingNow 每秒跳动（对齐右栏 Elapsed 口径），终态定格。

影响面：ui 新增 components/ProcessPillsBar；WorkspacePage 主挂载点 WorkPlanCardFromSegments → ProcessPillsBar；WorkPlanCard 本体保留（子代理详情卡 + PlanMarkerRow/StepStatusIcon 导出复用）；GLOSSARY「工作计划」词条主任务呈现句改写；ui 单测新增 process-pills-bar-ui（6 用例：胶囊渲染/空态/null/浮层锚定/点外收起/行点击直跳）；desktop e2e 无 plan-card 引用零影响；原型三变体全量快照留档 prototype/tri-list-cards 分支（原型的 ?variant= 切换条与分流接线不进 main）。
