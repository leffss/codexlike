# 规范与技能以磁盘为真相，技能正文按消息生效

全局与项目资源沿用文件作为唯一真相，不创建数据库中的第二份指令配置。为兼容共享技能，发现 `.codexlike` 和 `.agents` 两套目录；同名时较近项目目录优先于较远目录及全局，同一层应用自有目录优先，Worktree 只读取实际副本。无效的高优先级条目不回退同名低优先级条目，避免错误来源被无声执行。

每条消息重新发现规范与技能索引，执行期间使用固定目录快照。技能正文仅在用户显式引用或模型按需加载时进入本轮上下文，轮末不持续激活；子代理继承规范与目录但各自加载正文。相较会话级激活，这避免无关技能随长会话积累及旧正文在恢复后继续影响任务，代价是后续消息可能再次读取技能。已加载文本本轮缓存，未加载文件如发生变化则明确拒绝混用版本。

技能和附属文本是受限配置资源，不是提权通道：允许在已发现的技能根内按需读取文本，不自动执行脚本、不改变工具审批；预览、当前运行和最近运行摘要分开展示，磁盘扫描结果不得冒充当前生效内容。
