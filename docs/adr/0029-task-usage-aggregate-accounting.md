# 任务用量：真实 usage 聚合记账，不逐调用明细

任务用量（见 GLOSSARY「任务用量」：任务自诞生起累计的模型 token 消耗）以 API 响应的真实 usage 为数据源，按「主任务/子代理 × 输入/输出」在任务上聚合为 4 个数持久化；凡以任务身份发起的模型调用（对话、子代理、compact、commit message 生成）全部计入，中断/失败轮尽力而为——API 报多少记多少，没报记 0。拒绝的替代方案：逐调用明细表（写放大，当下无消费场景）与存量任务估算回补（一个数字两种成色，账目含义反而糊掉）；聚合一旦落库明细不可重建，将来若需要明细，自本决定落地之日起新增明细表，聚合列保留。`cachedInputTokens`/`reasoningTokens` 暂不记录（provider 支持参差），需要时再加列。
