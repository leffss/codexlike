# UI 设计语言定案：留白呼吸（Notion 式）

全 UI 现代化重构的设计语言经五变体原型评审（分支 `prototype/ui-modern`，`?variant=` 切换实机对比，子代理并行各建一个谱系、纯 CSS 表达于同一真实工作台），用户选定 **D「留白呼吸（Notion 式）」**：暖白底、无边框、暖灰面（`#f7f6f3` 系）、大间距高行高、黑色 accent 主张、阴影只给悬浮物（弹层/浮钮）。语义 token 机制不变（ADR 0006：`data-theme` 双主题、styles.css 集中定义、组件只写语义 class），本决策重定 token **值**与组件排版参数——原型期单主题（浅色基调），实施期补齐深色套。范围覆盖 ui 包全部 web 面（工作台、设置页、新建任务起点页、全部弹层）；原生托盘菜单与系统对话框不在内。信息架构类 ADR（0018/0019/0020/0022/0026）全部冻结，本次只动视觉语言与局部表达。

## Considered Options

评审五谱系（均构建于同一骨架 `prototype/ui-modern`，评审后全集留分支存档，不入 main）：

- **A · Apple/visionOS 玻璃**：毛玻璃 + iMessage 气泡 + 环境渐变，败于系统级 vibrancy 需改 Electron 窗口参数、玻璃面在长文阅读场景噪声偏高。
- **B · 扁平极简（Fluent 式）**：零阴影发丝线高密度，败于过密的文档感与工作台「工具」气质过重。
- **C · Linear/Arc 现代暗色**：indigo 精密暗色，败于本应用默认浅色（ADR 0006），暗色基底与双主题体系相逆。
- **D · 留白呼吸（选定）**：暖白无边框、内容优先、排版即设计——与「本地长文对话工作台」的阅读主导场景最契合。
- **E · 键盘优先命令面板（Raycast 式）**：近黑高对比红 accent，败于全屏高对比的视觉疲劳与 accent 单色承载不了状态色体系。

败者变体保留在分支上作为后续微调的素材池（混搭某变体的局部手法时按需取用）。

## Consequences

- 实施为**纯样式层重构**：零新依赖、内联 SVG 图标纪律不变、所有 testid 与交互行为不动、信息归属不变。
- 每步合入硬门槛：40 个 e2e 场景 + 55 个 ui 单测全绿（改 e2e 交互面的票合入前实跑对应场景）。
- 圆角体系 8–12px、行高 1.7–1.75、暖灰层级（`#f7f6f3`/`#ebeae8`/`#787774` 系）、accent 黑主张 `#2f3437` + 链接蓝 `#2383e2` 降调使用——具体值以原型 `variant-d.css` 为基线，实施折回 token 与组件类。
- 深色主题无原型覆盖：实施期按 D 的暖灰逻辑新设计深色套（非暗色反转），Monaco/highlight.js 色随动。
- 设置页七个分区与各弹层未出独立原型，按 D 的 token 与组件皮肤直接实施，重要分歧点实机评审。
