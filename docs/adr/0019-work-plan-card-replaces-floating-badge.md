# 工作计划：悬浮进度环徽章退役，正文与输入区之间的长条形进度折叠卡

ADR 0016 复验收稿的 fixed 悬浮 44px 进度环徽章（可拖动/位置记忆/右键复位）实测暴露三类问题：悬浮件遮挡它漂过的消息上下文；轻点/拖动/右键三套交互与位置记忆、贴边避让、锚测量一整套复杂度只为「放哪儿」服务，而非「读到进度」；右栏常驻（ADR 0018）后中列频繁推窄，浮动默认位与消息区左缘的锚定关系随布局变化衰减。经三变体原型对比（分支 prototype/plan-card：A 单行状态条 / B 分段轨道 / C 百分比+步骤预览），用户选定变体 C 折叠进生产：**长条形进度折叠卡**——固定槽位、无拖拽、与正文列同宽。

## 关键边界

- **槽位**：消息正文与消息队列/输入框（或交互面板）之间——「读到哪、接下来做什么」的关注点所在，与「已开启自动批准」提示卡同槽（在其上方）；宽度对齐正文列（contentWidthClass + contentPadding，居中基准与消息列、输入区完全一致），消息流 flex-1 收缩让位，展开不撑破布局。
- **结构（变体 C）**：头行＝计划图标 + 标题 + 百分比徽章 + N/M 计数 + 折叠箭头，整卡可点；收起态第二行内联预览当前步骤（静态箭头）与下一步（空心圆）——不展开也能读到进行中与接下来做什么；展开态完整步骤清单（完成项删除线、max-h-72 内部滚动）。全部完成时收起态只留一行「全部完成」。开合记忆走 collapse-memory 任务作用域（ADR 0011 渲染层内存态），默认收起。
- **流内标记行不变**：update_plan 调用在消息流原位仍只留一行极简标记（PlanMarkerRow，ADR 0016），当前状态常驻看卡、历史回看走流内。
- **无计划时不占布局行**（渲染 null）；任务切换随 key 重挂载，开合态不跨任务串。

## 取舍

- 拒绝变体 A（单行状态条，进度为底缘细轨）与变体 B（分段轨道为主视觉）：结构完整快照留在 prototype/plan-card 分支；C 的胜出理由是收起态信息密度最高（百分比 + 当前 + 下一步三段信息零交互可得），且百分比徽章比进度环/轨道对「还差多远」的传达更直接。
- 拒绝「保留悬浮形态但去掉拖拽」：悬浮件遮挡消息上下文的问题与拖拽无关，固定槽位才是解。
- 删除 collapse-memory 的位置记忆三函数（rememberedPosition/setRememberedPosition/clearRememberedPosition）：唯一消费者是退役徽章，渲染层内存态的开合记忆保留。
- 中文标题不音译进分支名等本 ADR 无关决策不在范围（git 分支名规范另见 agent-core `taskBranchName`）。

影响面：ui 新增 components/WorkPlanCard（进度折叠卡 + 标记行 + 三态图标），删除 components/WorkPlanBanner（悬浮徽章全套：拖动/位置记忆/右键菜单/贴边避让）；MessageStream 摘除徽章挂载（标记行改从 WorkPlanCard 导入），WorkspacePage 中列新增卡挂载；collapse-memory 删位置记忆三函数；GLOSSARY「工作计划」词条改折叠卡表述；e2e work-plan 场景改卡交互基线（testid plan-card 系）。
