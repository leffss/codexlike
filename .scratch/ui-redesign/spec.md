# Spec: 主窗口布局重构（ui-redesign）

Status: ready-for-agent

## Problem Statement

主窗口纵向空间利用率低：标题栏一整行只放品牌名；workspace-info 一整行只显示一条工作区路径；消息流上方最多同时堆 5 条提示横条（保存失败 / 模型配置不可用 / 上下文告警 / 工作区共享 / 自动批准状态）；右栏「规范与技能」「改动」两面板垂直堆叠强制共享高度。打开一个任务时并发分区可达约 10 个，界面拥挤、重点被稀释。

## Solution

按 UI 布局原型定稿的**变体 D（混搭）**重排主窗口（原型分支 `prototype/ui-redesign`）：

- 标题栏改为**任务上下文行**：任务名 + 项目·worktree 徽章（完整路径收进徽章）+ 任务搜索，消息流直接从标题栏下方开始；无任务时回退品牌展示
- workspace-info 整行取消
- 五类提示改为**右下角 toast**，完全不占布局行
- 右栏改 **overlay 抽屉**：「规范与技能 / 改动」在同一浮层内 tab 切换，消息流不再被挤压
- 左栏保持常驻；补窗口最小尺寸底线；视觉在现有 token 体系内做现代化统一

## User Stories

1. 作为用户，打开任务时我想在标题栏直接看到当前任务名，以便随时知道自己在哪
2. 作为用户，我想把鼠标放到标题栏徽章上看完整工作区路径与来源目录，以便不占一整行也能查路径
3. 作为用户，没有打开任务时标题栏回退为品牌展示，以便窗口不显得空而怪
4. 作为用户，我想从标题栏直接发起任务搜索并切换任务，以便少一次视线跳跃
5. 作为用户，提示以 toast 从右下角浮出，以便消息流上方不再被横条层层占据
6. 作为用户，我想手动关掉某条 toast，以便不被持续干扰
7. 作为用户，多条提示同时出现时堆叠展示，以便一条不漏
8. 作为用户，右栏面板打开时消息流宽度不变，以便长消息阅读不被挤压
9. 作为用户，我想在「规范与技能」「改动」两个面板间 tab 切换，以便它们不再抢高度
10. 作为用户，改动面板里文件列表、diff、分支与提交能力保持原样，以便审查改动的流程不变
11. 作为用户，规范面板里 AGENTS.md 快照、技能列表与加载记录保持原样，以便照常检查注入
12. 作为用户，窗口缩小到尺寸底线以下就缩不动了，以便布局不破
13. 作为用户，1280×800 默认窗口下各区域不挤压不换行，以便开箱体验良好
14. 作为用户，浅色/深色主题下新布局都正常，以便切换主题无死角
15. 作为用户，新建草稿时选择目录与工作区模式的入口仍可用，以便创建流程不回归
16. 作为用户，标题栏拖动移动窗口、窗口控制按钮照常工作，以便无边框窗口习惯不变
17. 作为维护者，testid 与 e2e 随布局同票联动，以便测试债不堆积
18. 作为维护者，全量 e2e 链在收尾票终验全绿，以便合并信心充足

## Implementation Decisions

- **定稿方案**：原型变体 D（访谈六项决策：范围=主窗口、视觉=token 体系内现代化不引入组件库、允许收纳不删功能、标题栏=任务上下文行、e2e 同票联动、补窗口底线）。primary source：`prototype/ui-redesign` 分支。
- **标题栏**：现品牌标题栏重写为任务上下文行组件；承载任务名、「项目 · Worktree/本地」徽章（hover/click 展示完整工作区路径与来源目录）、任务搜索（现有任务搜索整体迁入，能力不减）、主题/设置/窗口控制。无任务时回退品牌展示。拖动区（标题栏拖拽 + 控件免拖）行为保留。
- **workspace-info 行**：整行删除。路径、Worktree/本地 徽章、来源目录全部收进标题栏徽章；草稿场景的目录选择与工作区模式选择入口保留可用（就地收纳，不删功能）。
- **提示 toast 化**：渲染层内存态 toast 管理器（不持久化）；五类提示全部迁为右下角 toast；多条堆叠、可关闭；消息流上方不再渲染任何常驻横条。
- **右栏 overlay 抽屉**：两面板收进同一浮层容器，tab 头切换；浮层覆盖在消息流上（不挤压内容列宽度），宽度沿用原型的 30rem、上限 60% 视口参数；标题栏开关按钮与抽屉状态 aria 同步；面板内部滚动、刷新、独立关闭能力不回归。
- **容器分档**：`@container/task` 三档内容列断点行为保留；抽屉浮出后「面板开合不改变容器宽度」更彻底；`width-tiers` 场景按抽屉自身宽度约束重新基线。
- **窗口底线**：主进程窗口配置补 minWidth/minHeight。
- **视觉现代化**：语义 token 双主题架构不动（ADR 0006）；密度、圆角、留白、层次按 D 变体统一走查。
- **测试定位器**：布局变更 testid 同票联动，沿用「会话改为任务」（ADR 0014）已跑通的模式；定位器约定与检查脚本继续强制。

## Testing Decisions

- 主缝 = 窗口级 e2e（现有 Playwright 全量链 + 链外场景）；辅缝 = 组件级 vitest（现有静态渲染测试先例）。不新增缝隙层。
- 只测外部行为：断言可见文案、testid、aria 状态与窗口行为，不断言组件内部实现。
- 结构耦合场景随票联动：window-controls、width-tiers（重基线）、projects-sidebar、entry-consistency、worktree、theme、packaged。
- 每票收尾跑链内相关场景；终票跑全量链（链内 33 + 链外 5）。

## Out of Scope

- 设置页重排（仅跟随 token 受益）
- 左栏折叠/收纳（三变体一致保留常驻）
- 消息流内部结构（轮次聚合、已工作折叠区、工具卡）
- 主题 token 架构变更、引入组件库
- 多任务 tabs（变体 C 未入选）
- 全局搜索（Ctrl+K）新能力——本次只迁移现有任务搜索
