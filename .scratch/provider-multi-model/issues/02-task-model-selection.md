# 02: 任务与子代理的模型级选择（二元组）

**What to build:** 用户在输入框旁的模型选择器里平铺看到每个「Profile 名 · 模型名」选项，一步选到具体模型；任务跨重启记住所用模型，恢复后续跑不重选。所选模型已从 Profile 删除时提示「已保存的模型不可用」并回退列表第一项；新建任务默认用第一项。子代理全局设置升级到模型级（选到具体模型），未配置时跟随主任务当前所用模型。`/model` 命令同步列出「Profile · 模型」。SQLite 存量任务（无 model 记录）回退第一项。决策依据 ADR 0024（无「默认模型」跟随概念是刻意取舍，勿「修复」）；符号定位见 `../notes.md`；用户故事见 `../spec.md` 6–12、18。
