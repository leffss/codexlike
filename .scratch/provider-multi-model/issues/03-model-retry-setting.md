# 03: 模型请求重试次数（执行设置）

**What to build:** 用户在设置页「执行」分区调整模型请求重试次数（0–10，默认 2）：网络不稳时调大更耐受，调试时设 0 快速失败。改动即时保存、只影响后续执行（已开始的执行用开始时的值，ADR 0017 语义）；配置经 resolver 范式注入（agent-core 不依赖存储实现），作用于对话、compact、子代理全部模型请求；重试耗尽后的中文失败提示适配配置值。与票 01/02 完全正交，可并行。决策依据 ADR 0024「重试不做 failover」边界与 ADR 0017 执行设置范式；符号定位见 `../notes.md`（agent-settings resolver 装配先例）；用户故事见 `../spec.md` 13–16。

**Blocked by:** None（可立即开始，与 01/02 正交并行）

**Status:** ready-for-agent
