# 02: 项目归属选择器

**What to build:** 新建任务页标题行右侧新增「项目」选择器：可选某个项目或「不选项目（独立任务）」。选择某项目即切换到该项目入口的持久草稿（文字、发送偏好随之恢复），选「不选」切到独立入口草稿——切换语义等同从对应入口进入（复用既有 loadNewDraft 路径，持久化模型一寸不动）；工作区行形态随归属即时变化，切换时重置独立任务的已选目录状态。`/new` 与组头「+」的语境直达照旧。

**Blocked by:** 01（居中起点页骨架）

**Status:** ready-for-agent

- [ ] 选择器列出「不选项目（独立任务）」与全部项目；初始值为进入入口的语境
- [ ] 切到某项目：工作区行变项目目录 + 本地/Worktree；该项目入口持久草稿的文字与设置恢复到输入壳
- [ ] 切到不选：工作区行变独立任务形态；独立入口持久草稿恢复；已选目录状态重置
- [ ] 切换后发送首条消息，任务按当前归属创建（项目任务/独立任务各验证一次）
- [ ] 启动现场上报的 target 随切换更新（切走的入口现场不被错误恢复）
- [ ] 单测覆盖：切换驱动工作区形态、草稿内容随切换恢复/保留
- [ ] 归属选择器变更随 e2e 交互面记录，供 05 号票实跑（本票不跑 e2e）
