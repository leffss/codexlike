# 01: 居中起点页骨架转正

**What to build:** 把原型定稿的变体 A「决策台」（修订版）转正为生产组件：从任一现有入口（顶栏菜单/组头「+」/`/new`/冷启动）进入新建任务时，主列呈现 800px 居中起点页——标题行（左「新建任务」、右侧语境暂为入口静态语境）、工作区单独成卡（项目任务：路径 + 本地/Worktree 切换；独立任务：专用目录文案 + 选择已有目录/回退）、审批/模型/思考三项一级控件、专属输入卡壳（更大输入区、placeholder 含 `/`·`@`·`$` 提示、圆形上箭头发送按钮，空输入禁用）、首条发送成功即时硬切任务视图、失败中文提示并保留输入与设置。正式任务的 MessageComposer 与消息流布局零波及。结构以 `prototype/new-task-start` 分支变体 A（42f9d95）为准，但代码按生产标准重写（原型受 throwaway 约束，不直接提升）；composer 子件按需抽取共享，抽取不允许改变正式任务侧行为。

**Blocked by:** None（can start immediately）

**Status:** ready-for-agent
