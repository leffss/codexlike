# 03: 滚动跟随状态机

**What to build:** 新建无 DOM 依赖的跟随纯函数模块(FOLLOWING/DETACHED 状态机、输入意图识别、scroll 事件滞后一帧的竞争对账、阅读位置恢复计算),接入消息流:贴近底部自动跟随最新内容,用户上翻立即脱离且不被流式输出拉回,提供"回到最新"入口,发送新消息强制回底。完成后流式输出期间页面自动跟随、翻历史不被打扰——"不能自动跟随滚动"的修复。滚动竞争逻辑(用户上滚与流式内容更新同帧)以纯函数单测确定性重放。[规格](../spec.md)滚动跟随与阅读位置记忆组用户故事;机制参考 [ZCode 调研报告](../../../../docs/research/zcode-message-stream.md)第一节。

**Blocked by:** 01(在重构后的消息段渲染结构上接线)。

**Status:** ready-for-agent

- [ ] 跟随纯函数模块无 DOM/React 依赖,单测覆盖:状态机裁决、滚轮/触摸/方向键意图识别、竞争对账(最近用户向上意图同帧让位)、阅读位置恢复计算
- [ ] 距底 ≤48px 判定贴底;贴底时流式增量、工具卡更新、折叠变化自动跟随
- [ ] 只有真实用户输入改变跟随态:程序化贴底与布局测高产生的滚动不动状态机
- [ ] 用户上翻立即脱离跟随;脱离期间任何内容更新不夺滚动权
- [ ] "回到最新"入口可见性 = 脱离跟随且有消息;点击或滚回底部附近恢复跟随
- [ ] 发送新消息强制回底并进入跟随
- [ ] 贴底用即时 scrollTop 赋值(非 smooth);滚动容器 scrollbar-gutter 稳定、禁用原生 scroll anchoring
- [ ] 阅读位置记忆包含"离开时是否贴底":贴底记忆恢复到当前最新并跟随,否则恢复像素位置;现有跨会话/重启 <4px 精度断言不回归
- [ ] 新增 e2e 场景:跟随→上翻脱离→回到最新→恢复跟随
