# 02: 切换会话时完整保留执行现场

**What to build:** 用户在多个并行会话之间切换时，后台任务与等待继续；切回仍在运行的会话立即看到完整正文、工具记录和待处理交互。侧栏能区分执行、等待、完成未查看、失败和中断，不依赖当前打开的页面维持运行信息。

**Blocked by:** 01 — 建立项目与独立会话的新建闭环。

**Status:** ready-for-agent

**Spec:** [会话工作台重构规格](../spec.md)

## Acceptance criteria

- [ ] 当前查看的会话与正在执行的会话分离，项目会话和独立会话均可并行；切换项目或会话不停止执行或取消等待。
- [ ] 完整运行现场可经统一公开接口重新取得，不只保存在当前 renderer 页面或只依赖轮末落库历史。
- [ ] 模型尚未完成时 A→B→A，A 已生成正文立即完整显示，后续增量继续接上；不等待最终完成事件补全。
- [ ] 切换前后工具开始、输入、输出和终态完整；错过工具开始事件也不导致工具结果永久丢卡。
- [ ] 取得初始现场与接入后续事件之间不漏事件、不重复消息或工具卡片；会话与执行标识防止旧执行迟到事件污染新执行。
- [ ] 后台审批、交互问答及子代理所属请求保持在正确会话；用户响应只影响对应请求，不因切换而错误回答或恢复别的会话。
- [ ] 侧栏明确显示执行中、等待用户处理、完成未查看、失败和中断；查看状态与执行状态分离，查看不会改变任务运行结果。
- [ ] 停止任务仍是显式操作；停止后的事件不能把已停止会话恢复为运行中或追加到别的会话。
- [ ] 后台逐条输出不成为最近使用排序的输入，不使列表反复跳动；票 05 的排序沿用此规则。
- [ ] 不增加未经确认的全局并发禁止规则，不改变既有子代理并发与授权限制。
- [ ] 不以运行现场完整为由扩大历史持久化范围；现有运行期思考内容的落盘策略保持。

## Verification

- [ ] 用可控模型和事件闸门在生成未结束时进行切换，断言正文增量和工具记录在中途即可取得；不能只检查最终正文。
- [ ] 覆盖初始现场与增量接续、错过工具开始但收到结果、停止后迟到事件以及两个会话交错输出。
- [ ] 真实 Electron E2E 操作 A→B→A，检查正文、工具卡、等待用户交互及侧栏状态；同时验证独立会话和项目会话组合。
- [ ] 回归跨会话审批隔离、问答队列和主任务停止联动，保留现有有效权限与子代理测试。

## Scope boundary

本票保证当前应用生命周期内的运行现场完整；持久草稿与偏好由票 03 完成，退出中断和真实重启由票 08 完成。不加入退出后的常驻执行或自动续跑。
