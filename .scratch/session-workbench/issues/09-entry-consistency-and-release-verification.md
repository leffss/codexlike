# 09: 统一所有入口并完成整体验收

**What to build:** 新会话工作台各功能组合后保持一致：按钮、快捷入口和斜杠命令走同一管理规则，旧的目录派生和全局状态路径退出使用，完整桌面体验通过构建、类型、测试与打包冷启动验收。

**Blocked by:** 02 — 切换会话时完整保留执行现场；03 — 持久保存草稿、阅读位置与会话设置；04 — 接入延迟创建的 Worktree 与共享目录提示；05 — 完成侧栏整理与归档恢复；06 — 加入跨项目会话搜索；07 — 安全调整归属与移除项目；08 — 完成退出确认与重启恢复。

**Status:** ready-for-agent

**Spec:** [会话工作台重构规格](../spec.md)

## Acceptance criteria

- [ ] 全局新建、项目旁新建、会话内快捷入口及 `/new` 遵循相同上下文规则：独立入口无项目归属，项目入口保留显式项目归属，不从 Worktree 执行路径派生新项目。
- [ ] 归档、恢复、重命名及已有相应斜杠命令共享管理规则，导航结果一致；不得绕过活动状态或文件保护检查。
- [ ] 验证项目和独立会话在新建、切换、搜索、归档、移动及重启的组合场景下仍归属正确，草稿和设置不串用。
- [ ] Worktree 会话移出后可搜索与归档，重启仍保留来源，符合条件可移回；移除来源项目不误删已独立的记录或任何 Worktree 文件。
- [ ] 搜索结果在重命名、归属变更、归档恢复、项目移除后反映真实记录，不残留可发送到已移除会话的入口。
- [ ] 后台输出不使排序跳动、覆盖输入、打断阅读或取消用户交互；切回现场完整，不依赖最终消息补全。
- [ ] 所有会话管理入口使用新模型，移除不再有调用者的目录派生分组、旧全局偏好及自动数量清理路径；清理范围限于本重构相关代码。
- [ ] 保留执行审批、对话内交互问答、子代理、文件和终端边界、模型协议、主题以及消息级资源等既有有效能力。
- [ ] 替换与新语义冲突的旧测试，不能为绿色结果删除仍然有效的安全断言；旧数据迁移不再作为验收要求。
- [ ] 真实界面检查常驻侧栏和单主区的完整路径，包括长标题、空项目、无结果、归档列表及当前会话被移除；不要求新增标签页、分屏或分类功能。
- [ ] 打包后的冷启动可以在应用数据父目录尚不存在时创建新数据环境并正常打开；不依赖开发态目录残留。
- [ ] 更新面向使用者和维护者的相关文档，说明项目与独立会话、新建、归档、退出及不兼容旧数据的边界；将尚未实施的设计说明更新为实际交付状态。
- [ ] 测试和构建检查直接取得退出码，不接截断管道；分别报告实际通过、失败和未执行项，不把文档检查或静态渲染冒充完整 E2E。
- [ ] 不在本票擅自清理真实用户数据、提交或推送 Git、发布外部服务；这些操作仍按各自授权执行。

## Verification

- [ ] `pnpm build`、`pnpm typecheck`、`pnpm test` 实际执行并记录结果；干净环境先构建，避免 desktop/UI 读取陈旧 Core 产物。
- [ ] `pnpm test:e2e:all` 实际执行，并将本重构新增 E2E 接入可运行的检查入口，确保完整套件覆盖新行为。
- [ ] 核对审批、子代理、用户交互、Worktree、命令等专项仍在验证范围，避免只跑基础冒烟。
- [ ] `pnpm dist` 后执行 `pnpm test:e2e:packaged`，验证真实产物与冷启动；完整 E2E 不等价于已验证打包产物。
- [ ] 按规格用户故事和票 01–08 验收项做覆盖映射，识别跨票遗漏并补齐必要回归；每张前置票自己的测试不能拖到本票才开始写。
- [ ] 完成交付差异审查，确认未引入无关架构替换、权限回退或文件删除路径；清楚列出仍受环境限制而未验证的行为。

## Scope boundary

本票是整合、入口一致性和交付验收，不是把缺失的核心功能集中到最后完成。此前各票须先交付自己可独立展示或验证的纵向行为。
