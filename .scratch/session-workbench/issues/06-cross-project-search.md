# 06: 加入跨项目会话搜索

**What to build:** 用户从统一搜索入口按标题和消息正文查找独立会话及项目会话，可选择纳入归档记录，并从结果进入正确会话，不受侧栏折叠或当前项目限制。

**Blocked by:** 05 — 完成侧栏整理与归档恢复。

**Status:** ready-for-agent

**Spec:** [会话工作台重构规格](../spec.md)

## Acceptance criteria

- [ ] 搜索同时覆盖所有项目会话和独立会话，不依赖当前选中项目或当前 renderer 已加载的历史。
- [ ] 标题与消息正文均可检索；仅标题匹配或仅正文匹配的会话都能被找到，不把“搜索”实现成当前侧栏名称过滤。
- [ ] 默认结果与归档选项一致；用户可明确开启或关闭归档记录搜索，结果同步更新。
- [ ] 结果可区分项目归属、独立会话和归档状态，不将同目录会话误认为同一项目。
- [ ] 从结果打开对应会话时定位到正确历史，归档会话可查看及恢复；打开搜索结果不会自动停止后台执行。
- [ ] 重命名、归档、恢复和新消息持久化后，后续查询反映实际内容；不要求尚未完成的流式片段实时全文索引。
- [ ] 快速输入与异步查询不会让旧查询结果覆盖新查询，清空查询或无匹配时状态明确。
- [ ] 搜索仅查询会话数据，不将 provider 密钥、应用私有配置或磁盘目录内容纳入正文搜索。
- [ ] 查询接口和 UI 都可处理空输入和正常特殊字符，不拼接不安全的查询表达式。

## Verification

- [ ] 用真实 SQLite 建立项目会话、独立会话及归档会话，分别以标题和消息正文验证结果与归档过滤。
- [ ] 重开数据库后仍能搜索持久历史，证明不是仅检索 renderer 内存。
- [ ] 真实 Electron E2E 从跨项目搜索打开正确会话并查看归档结果；验证项目折叠不影响搜索覆盖。
- [ ] 覆盖快速查询切换、无结果以及归档或重命名后的再次查询。

## Scope boundary

本票只交付既定的会话检索，不增加标签、文件夹、复杂检索语言、跨磁盘全文索引或搜索式自动归类。
