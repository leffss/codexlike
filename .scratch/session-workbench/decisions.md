# 会话工作台重构：已确认设计

**阶段：** Q1–Q13、整体范围、测试方式及九张任务票的拆分均已由用户确认。[正式规格](spec.md) 与 [实施任务索引](issues/README.md) 已发布，尚未进入业务实现。此文件保留需求决策背景；实施与验收以正式规格和对应任务票为准。

## 目标

整体替换现有会话管理，而不是在旧界面上补按钮。参考 Codex / Claude Code 桌面版的工作台方向，但以下经用户确认的行为才是验收依据，不假定参考产品的具体实现。允许重做会话模型、持久化、状态管理、IPC 与界面，不兼容旧会话管理数据。

## 组织与导航

- 常驻侧栏加单会话主区；本次不做多标签页或分屏。
- 侧栏分别组织独立会话和各项目会话。全局「新建独立会话」不依赖项目；项目旁「＋」创建项目内会话。
- 项目由用户添加本机目录后独立存在，没有会话也保留；普通目录可用，不要求 Git 仓库。项目可折叠。
- 会话支持置顶；非置顶会话按最近使用排序，后台逐条流式输出不驱动列表反复跳动。
- 跨项目搜索标题和消息正文，同时覆盖独立会话；可选择纳入归档会话。
- 侧栏清晰区分执行中、等待用户处理、已完成但尚未查看、失败或中断。
- 不加入标签、文件夹或多级分类。

## 新建与草稿

- 点击新建先进入草稿页，首次发送才创建正式会话，自动命名并可手动重命名。
- 每个项目保留一份新会话草稿，独立会话入口另保留一份；切去旧会话不会丢失草稿。
- 正式会话也各自保存输入草稿、阅读位置和设置，重启后恢复。
- 首次发送前不创建 Worktree，不在历史列表中产生空会话。

## 工作区与项目归属

- 工作区是实际执行目录，不等于项目归属；界面明确展示当前工作区。
- 项目内新会话默认本地模式，可在首次发送前选择 Worktree，不强制弹出模式选择对话框。
- 同项目的本地会话可并行；已有其他本地会话执行时提示共享目录风险，不一刀切禁止。
- 独立会话默认使用应用管理的专用持久目录，首次发送时创建；也可在首次发送前指定已有本机目录。指定目录不会自动添加或归属项目。
- 独立会话首版不直接提供 Worktree 创建入口，需要隔离开发时从项目内创建。
- 首次执行开始后工作区固定。项目归属调整只影响组织，不搬文件、不改分支、不重写历史。
- 无执行且无等待用户回应时，独立会话可以移入目录匹配的项目，项目会话可以移出成为独立会话。
- Worktree 会话移出项目后仍保留来源信息，移回时只能归属来源项目。

## 执行与恢复

- 多个会话可以同时执行；当前查看哪个会话不控制哪些任务运行。
- 切换会话、项目不取消任务或等待中的用户交互。
- 切回运行中会话时，正文增量、工具卡片、执行状态及待处理交互完整可见，不必等最终消息补全。
- 各会话分别保留普通输入和问答草稿、阅读位置；不因切换互相串用。
- 真正退出应用前，若有运行或等待用户处理的任务先提示；确认退出则停止任务并取消等待。
- 重启恢复项目、会话、历史、草稿、阅读位置和设置；未完成执行显示为已中断，不自动继续或重放命令，由用户决定下一次发送。
- 本次不做退出应用后的常驻执行或完整执行检查点恢复。

## 会话设置

- 模型选择、思考档位、审批模式按会话独立记忆，重启后保留。
- 调整只影响下一次发送，不改变已开始的执行或历史。
- 新会话采用应用默认模型及思考档位，审批模式从 `ask` 开始；不从其他会话继承 `full-access`。
- `full-access` 仍需显式开启并保留风险确认，不改变审批和交互问答的区别。

## 整理与文件安全

- 会话归档只从日常列表隐藏，仍可搜索、查看、恢复，不删除 Worktree。
- 首版不额外提供永久删除单条会话。
- 移除项目需明确确认，会移除项目及其所属会话记录，但保留项目目录和 Worktree 文件；不会因目录相同而连带移除独立会话。
- 有执行或等待用户回应时，先停止才能归档该会话、移除项目或调整归属。
- 取消按数量自动清理 Worktree；磁盘清理与会话整理分开，本次不因此增加完整磁盘清理产品。
- 不兼容旧数据不等于删除用户源代码或工作成果；本轮设计阶段不清理任何现有数据。

## 一致性与验收重点

1. 项目内新建、全局独立新建、快捷入口和斜杠命令遵循一致的组织与创建规则，不误把 Worktree 路径派生为新项目。
2. 切换期间正文、工具记录、用户交互状态不丢失，不跨会话污染；后台更新不造成侧栏跳动。
3. 草稿发送不会留下额外空会话；新建、创建 Worktree 失败时可恢复操作而不伪装成功。
4. 归档、恢复、移除和调整归属从不同入口触发时结果一致；所有整理操作遵守运行保护和文件保留边界。
5. 重启验证持久设置、草稿、历史和阅读位置，并验证任务保持中断、工具没有重放。
6. 搜索覆盖项目会话与独立会话，归档开关有效。

以上是行为验收目标；具体测试接口与任务拆分在正式规格阶段确认。

## 与既有设计的关系

- [ADR 0010](../../docs/adr/0010-session-workbench-project-membership-and-workspace.md) 记录项目归属与执行工作区分离等关键取舍。
- ADR 0005 的目录自动派生项目规则被本目标替代，Worktree 来源信息仍需保留。
- 模型和思考档位的设置归属调整为会话级，不要求改变 ADR 0008 的 provider 选择。
- 延续 ADR 0009 的用户交互语义，以及退出取消、重启不恢复执行的原则。
- SQLite、类型化 IPC、Agent Core 与 Electron 解耦等无关架构选择保持，不把“不兼容旧数据”扩大成无边界的全应用重写。
