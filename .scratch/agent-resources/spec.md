# 全局/项目规范与按需技能

Status: done

## 已批准范围

- AGENTS 自动注入；全局 CODEXLIKE_HOME/AGENTS.md（默认 ~/.codexlike），项目 Git 根到工作区逐层发现，非 Git 仅工作区。保留 32 KiB 总量限制并展示截断诊断。
- skills 来源：全局应用目录/skills 与 ~/.agents/skills；项目目录链每层 .codexlike/skills 和 .agents/skills。Worktree 使用副本，不回退 origin。
- 同名优先级：近项目层 > 远项目层 > 全局，同层 .codexlike > .agents。无效高优先级项不回退低优先级同名项。被覆盖和无效来源可见。
- SKILL.md 标准 YAML frontmatter：name、description 必需，name 与目录名一致。仅有界扫描元数据，按需读正文。名称使用小写字母/数字/单连字符，最长 64 字符，至少包含一个字母以避免金额歧义；发现、补全和调用使用同一校验。
- 每条用户消息刷新规范和索引；运行期间固定目录快照。未加载文件变化报错，已加载文本缓存。
- 默认模型只看到技能索引；load_skill 按需加载。用户 $name 显式多技能引用由宿主在首次模型请求前加载，按出现顺序去重；错误时不发送部分加载请求。
- 正文仅当前消息有效，不写入 mentions，不因恢复或 compact 自动激活。
- 子代理继承相同规范与目录快照，独立加载正文，主/子代理及并行子代理不共享激活状态。
- read_skill_resource 仅读取已加载技能目录内的文本；拒绝绝对路径、路径逃逸、越界符号链接、二进制和非普通文件。加载不运行脚本、不改变审批或普通工具权限。
- 预算：索引 16 KiB，单正文 64 KiB，单文本资源 32 KiB，单执行者本轮加载总量 256 KiB。正文/资源超限明确报错，不静默截断。
- 输入框 $ 补全支持键盘/鼠标，仅写回引用不直接发送；保留 / 命令与 @ 引用。忽略金额、转义美元符和代码中的 shell 变量。
- 只读“规范与技能”视图及 /status 区分当前运行快照、最近一轮摘要、下轮磁盘预览。索引/已加载文本纳入 token 估算；列出来源、覆盖及诊断。
- 不做文件管理/编辑、市场/安装、启停、远程技能、项目数据库配置或 .zcode/.claude 兼容。

## 验证接口

1. 资源模块公开发现、执行者加载接口：真实隔离文件目录测试覆盖、大小限制、YAML 与路径安全。
2. AgentSession/SessionManager 请求接口：mock 模型观察真实上下文，验证刷新、按需、显式、生命周期和恢复。
3. 子代理编排接口：观察子代理请求与工具事件，验证继承、隔离及审批。
4. 输入解析/菜单与 Electron 用户交互：$ 多技能、来源展示、错误反馈、/ 与 @ 回归。
5. Electron 本地 mock HTTP 请求：确保未加载正文不发送、显式首次注入、自主加载及资源回填、下一轮清理。

## 改动纪律

保留实施前已存在的主题等改动；不提交、不推送。新增 ADR 前重新检查编号及已有规划。运行 typecheck/test/check:adr/专项 E2E/全套 E2E，直接取退出码，不用管道截断输出。
