# 03: 工作台目标与视图的保存与恢复

**What to build:** 重新打开 CodexLike 时，回到退出前正在查看的工作台目标与所在视图：渲染层在目标或视图变化时经新增 IPC 上报主进程，主进程即时落盘到启动现场文件（低频事件不防抖）；冷启动逻辑的第一优先级从内存活动会话换成启动现场的工作台目标，回退链保持不变（目标失效→排序最前的未归档会话→新建草稿入口）；顶层视图初始值取启动现场。目标与视图两字段独立记录（设置页下目标仍是最后打开的会话）；归档会话照常恢复；草稿状态连同项目关联恢复（草稿文本本身仍由 workbench_state 既有机制恢复）。执行中会话重启后打开的是记住的会话，输入队列自动继续等既有行为不变。规格详见 `../spec.md`。
