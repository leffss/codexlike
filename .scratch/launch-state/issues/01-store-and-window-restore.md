# 01: launch-state store 与窗口现场恢复

**What to build:** 重新打开 CodexLike 时，窗口回到关闭前的位置、大小与最大化状态。主进程新增启动现场的 JSON store（落统一数据目录，尊重 `CODEXLIKE_HOME`，复用现有 JSON 读写基建的未配置/损坏容错），`whenReady` 内先读现场再建窗：有有效现场则按其 bounds 建窗（maximized 为真时先按正常态 bounds 建窗再 maximize）；现场与所有现存显示器可见工作区均无交集时保留尺寸、位置改主屏居中；部分越界与负坐标不修正；尺寸小于最小可用值时收紧。无现场或文件损坏时维持现有默认（1280×800 居中）。命名避开已被运行时最大化标志占用的 `WindowState` 一词。规格详见 `../spec.md`。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 首次启动（无现场文件）窗口为默认 1280×800 居中，现有冷启动行为不变
- [ ] 预写现场文件（bounds）后启动，窗口位置与尺寸与文件一致（e2e 从渲染层读窗口几何断言）
- [ ] 现场 maximized 为真时启动即最大化，且取消最大化后回到现场记录的正常态 bounds
- [ ] bounds 与所有现存显示器可见工作区均无交集时：尺寸保留、位置主屏居中
- [ ] 部分越界与负坐标位置照常恢复，不判失效
- [ ] 尺寸小于最小可用值时收紧到最小可用
- [ ] 现场文件损坏时当未配置处理，应用照常启动
- [ ] 单测：store 读写往返与损坏回退（照现有设置 store 单测先例）；显示器校验纯函数（无交集判定、尺寸收紧、居中回退）
- [ ] e2e：预写文件恢复场景与首启默认场景（真实 Electron，homeDir 隔离）
