# 02: 窗口现场保存——防抖与退出 flush

**What to build:** 用户移动、缩放、最大化/还原窗口后，启动现场文件随之更新：主进程监听窗口事件，move/resize 结束后防抖合并（约 500ms）落盘，maximize/unmaximize 切换后及时记录 maximized 标志与正常态 bounds；退出时经现有退出保存屏障 flush 防抖中未落盘的变化，保证崩溃或被杀时已过防抖期的现场不丢。保存的是「正常态 bounds + 是否最大化」，最大化期间不把全屏尺寸写进 bounds。规格详见 `../spec.md`。

**Blocked by:** 01（store 与建窗时序）

**Status:** done

- [x] 移动或缩放窗口结束约 500ms 后，现场文件的 bounds 与实际窗口一致
- [x] 连续拖动窗口期间不产生高频写盘（事件被合并）
- [x] 最大化与还原切换后，maximized 标志及时正确；bounds 始终记录正常态尺寸而非最大化尺寸
- [x] 退出（正常关闭与退出屏障路径）时防抖中的未落盘变化被刷出
- [x] 崩溃/被杀场景下，此前已过防抖期的现场在重开后照样恢复（与票01恢复链路衔接）
