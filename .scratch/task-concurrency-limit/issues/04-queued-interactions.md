# 04: 排队任务交互——后续消息进输入队列、中断出队

**What to build:** 排队任务不是死任务：排队期间输入框可用，再发的消息进入该任务的输入队列（排队任务在输入队列语义上视同「忙」，ADR 0013 机制原样复用不改），开跑后按序自动发出；点「中断」立即出队、任务回到空闲，已发消息保留在消息流，之后用户重新发消息触发执行（若仍满则重新排队）。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 排队任务输入框可用，提交的消息进入输入队列而非直接执行
- [ ] 开跑后输入队列按序自动发出
- [ ] 中断排队任务立即出队回空闲，侧栏/列表不再显示排队中，名额让给后续排队任务
- [ ] 已发消息保留在消息流；重新发消息时若满员则重新排队
- [ ] 输入队列既有行为（暂停、插话、跨重启）回归不受影响
- [ ] IPC 集成测试覆盖排队期入输入队列与中断出队
